# Built-in server plugins

Hidden: Source servers ran [SourceMod](https://www.sourcemod.net) plugins by Paegus, Ice and
others. Hidden: Rebuild has the popular ones built in, with the same cvars, so an old server config
keeps working. Every plugin is off until its main cvar turns it on; put the cvars in your
`server.cfg`.

This list is generated from the source code, so it's always the current build's.
